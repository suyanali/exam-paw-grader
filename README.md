# Exam Paw Grader

Exam Paw Grader 是一個以瀏覽器執行的離線跑考／OSCE 評分工具，設計重點是快速現場打分、Run 名單管理、修改紀錄與資料救援。

目前版本：**v0.2.0**

## 主要功能

- 匯入學生名單（學號、姓名）
- 隨機排序並依每 Run 人數自動分組
- 固定 Run 名單後可匯出／匯入
- 匯出給學生與教師查看的 Excel 名單
- 考試中標記缺考、彈性調整尚未完成的 Run
- 自訂多個大題、各大題細項與滿分
- 可儲存多套課程評分範本，並匯出／匯入評分設定
- 細項分數 ≤ 5 時使用快速按鈕
- 細項分數 > 5 時提供 ±5 快速調整與數字輸入
- 特殊事件紀錄，例如做錯、提示、超時等
- 可回頭修改任意 Run／學生的歷史成績
- 保存修改前後的 audit log
- 自動儲存至瀏覽器 IndexedDB
- 可匯出完整 JSON 救援備份並重新匯入恢復
- 最終成績匯出 Excel，主表會動態展開所有自訂評分細項與各大題總分
- PWA 支援：安裝後可離線使用，並具版本更新通知

## 最終 Excel 格式

主成績工作表會依當次評分設定動態產生欄位，例如：

```text
Run｜組內順序｜學號｜姓名｜
大題一-細項A｜大題一-細項B｜大題一-總分｜
大題二-細項A｜大題二-細項B｜大題二-總分｜
最後平均
```

另外保留事件紀錄與修改歷程工作表，方便日後查核。

## 使用方式

### GitHub Pages / HTTPS

建議部署在 GitHub Pages 或其他 HTTPS 靜態網站服務。首次開啟並成功載入後，可安裝成 PWA，之後可離線使用。

### 本機測試

PWA 的 Service Worker 不能從一般 `file://` 雙擊模式完整運作。若要測試安裝與離線功能，請使用 `localhost` 啟動靜態網站伺服器。

例如 Python：

```bash
python -m http.server 8000
```

然後瀏覽：

```text
http://localhost:8000/exam-paw-grader.html
```

若只需要基本評分功能，也可以直接以瀏覽器開啟 HTML；但 PWA 安裝、Service Worker 與更新機制需要 HTTPS 或 localhost。

## 資料安全與備份

評分資料主要保存在目前瀏覽器裝置的 IndexedDB 中。為降低考試途中資料遺失風險，建議：

1. 開考前先確認固定 Run 名單與評分設定。
2. 中場休息或重要階段下載一次 JSON 救援備份。
3. 考試完成後立即匯出最終 Excel 與完整 JSON 備份。
4. 不要在考試進行中清除瀏覽器網站資料或重設瀏覽器設定。

「清除所有資料／新一輪考試」會清除本次考試資料；已儲存的評分範本則保留，方便下次重複使用。

## 隱私

此專案本身不包含真實學生名單、學號、姓名或考試成績。README 與範例僅使用泛化／示意資料。

工具以離線使用為主要設計方向，評分資料不需要上傳到遠端伺服器即可完成主要流程。實際部署與使用時，仍請依所在單位的個資與成績資料管理規範處理匯出的 Excel／JSON 檔案。
