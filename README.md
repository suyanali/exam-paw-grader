# Exam Paw Grader

Exam Paw Grader 是一個可離線使用的跑考／OSCE 教師評分工具，可處理學生 Run 分組、現場評分、成績修改追蹤、備份救援與 Excel 成績輸出。

目前版本：**v0.2.5**

## 直接開始使用

**GitHub Pages：** https://suyanali.github.io/exam-paw-grader/

第一次使用需要連網。安裝成 PWA 並在線開啟一次後，主要評分功能可離線使用。學生名單與成績主要保存在目前裝置／瀏覽器的 IndexedDB。

## 安裝方式

### Windows / Chrome 或 Edge

1. 開啟上方 GitHub Pages 網址並保持連線，等頁面完整載入。
2. 可使用瀏覽器的「安裝」功能安裝成 App。
3. 安裝後先在線開啟一次，再斷網測試。

### Android / Chrome

1. 用 Chrome 開啟 GitHub Pages 網址。
2. 第一次保持網路連線並完整載入。
3. **請優先按頁面上方的「安裝 App」按鈕。**
4. 安裝後從主畫面開啟一次，再開飛航模式測試離線功能。

> 已確認部分 Android / Chrome 環境在同一 GitHub Pages 網域已安裝其他 PWA 時，從 Chrome 選單選「安裝應用程式」可能出現「無法開啟程式」。頁面內的「安裝 App」按鈕可正常安裝，因此 Android 請優先使用頁面按鈕。

### iPhone / iPad / Safari

1. 用 Safari 開啟 GitHub Pages 網址並保持連線。
2. 點「分享」→「加入主畫面」。
3. **「打開為網頁 App」要勾選。**
4. 加入後保持網路，先從主畫面開啟 App 一次。
5. 之後再開飛航模式測試離線功能。

## 完整操作流程

### 1. 匯入學生名單

名單至少要有「學號、姓名」兩欄。現在可直接使用 **CSV、XLSX、XLS、Apple Numbers**，也可從 Excel／試算表複製兩欄貼入文字框。

在「名單 / Run」頁：

- 按 **匯入原始名單檔** 可選擇檔案。
- 或貼上「學號、姓名」後按 **匯入名單**。
- 設定「每 Run 人數」。
- 按 **隨機排序並分 Run**。

若 Numbers 檔案因版本無法直接讀取，可先在 Numbers 輸出／傳送副本為 Excel `.xlsx` 再匯入。

### 2. 固定 Run 名單

確認分組後按 **固定目前 Run**。

建議保留：

- **固定名單 Excel**：方便提供學生、助教或其他教師查看。
- **固定名單 JSON**：日後可完整匯回 Exam Paw Grader，不必重新隨機。

### 3. 設定評分方式

進入「評分設定」，可設定大題名稱、icon、評分細項與各細項滿分，也可新增「做錯」、「提示」、「超時」等特殊事件。

可將目前設定儲存成課程評分範本；若要帶到另一台裝置，可匯出／匯入「評分設定 JSON」。

### 4. 現場評分

進入「現場評分」並選擇 Run，再依實際到站學生姓名選取學生。

- 細項滿分 **5 分以下（含 5）**：可按分數按鈕或直接輸入。
- 細項滿分 **大於 5 分**：可用 `−5`、`+5` 快速調整，也可直接輸入數字。
- 特殊事件按鈕可直接點選；再次點擊可取消，啟用中的事件會顯示勾選狀態。
- 每次分數異動都會自動儲存，不需另外按「儲存」。

### 5. 下一位學生

完成目前學生後按 **下一位學生**。系統會回到目前 Run 的學生列表，教師依實際到站者選取，不強迫固定順序。

### 6. 缺考與移 Run

可將學生標記為「缺考」。若後面 Run 因缺考導致人數不足，可用 **移 Run** 將尚未考試的學生移至其他 Run，系統會保留異動紀錄。

### 7. 修改以前的成績

進入「全部成績」，依 Run、學號或姓名找到學生後選擇「查看 / 修改」。修改後會保留 Before / After 歷程，方便日後查核。

### 8. 考試途中備份

進入「救援 / 輸出」→ **下載完整救援 JSON**。

建議在開考前設定完成、中場休息、大量評分完成後及考試結束時備份。若需要換裝置，可用 **載入救援 JSON** 恢復。

### 9. 匯出最終成績

按 **匯出最終成績 Excel**。主成績表會依評分設定自動展開，並包含最後平均及 **備註（特殊事件）**；另外保留事件紀錄與修改歷程，方便查核。

### 10. 開始下一輪考試

確認已下載最終成績與救援 JSON 後，按 **清除所有資料／新一輪考試**。這會清除本次學生、Run、成績、事件與修改紀錄，但已儲存的課程評分範本會保留。

## 資料安全

評分資料主要存在目前裝置與瀏覽器的 IndexedDB。考試進行中請勿清除這個網站的「網站資料／儲存空間」。建議使用「本機自動儲存 + 定期救援 JSON + 考後 Excel」三層備份。

## 版本更新

程式頂端會顯示版本號；偵測到新版時可按「立即更新並重新載入」。

**若目前版本使用正常，不需要特別更新。** 有需要使用新版功能，或目前版本遇到問題時，再連上網路更新即可。更新前仍建議先下載救援 JSON；程式更新本身不應清除既有評分資料。

## 隱私

公開專案不包含真實學生名單、學號、姓名或成績。匯出的 Excel / JSON 可能包含學生資料與成績，請依所在單位規範保存。
