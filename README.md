# Exam Paw Grader

Exam Paw Grader 是一個以瀏覽器執行的離線跑考／OSCE 教師評分工具，主要用於學生 Run 分組、現場評分、成績修改追蹤、備份救援與 Excel 成績輸出。

目前版本：**v0.2.0**

## 直接開始使用

**GitHub Pages：** https://suyanali.github.io/exam-paw-grader/

第一次使用時需要連網開啟上方網址。安裝成 PWA 並完成第一次載入後，主要評分功能可離線使用；學生名單與成績保存在目前裝置／瀏覽器的 IndexedDB，不需要將成績上傳到伺服器。

## 不同作業系統如何開始

### Windows / Chrome 或 Edge

1. 用 Chrome 或 Edge 開啟 GitHub Pages 網址。
2. 第一次請保持網路連線，等頁面完整載入。
3. 若網址列出現「安裝」圖示，可直接按下安裝；Chrome 也可從右上角選單尋找「安裝 Exam Paw Grader」或類似選項。
4. 安裝後可像一般程式一樣從開始功能表開啟。
5. 正式考試前建議先關閉網路測試一次，確認程式仍能正常開啟及操作。

不安裝也可以直接使用瀏覽器版本；但正式跑考建議安裝成 PWA，操作上較接近獨立 App。

### Android / Chrome

1. 用 Chrome 開啟 GitHub Pages 網址。
2. 第一次保持網路連線並完整載入。
3. Chrome 選單選擇「安裝應用程式」或「加到主畫面」。
4. 安裝後從手機／平板主畫面開啟 Exam Paw Grader。
5. 正式使用前建議切成飛航模式測試一次離線開啟。

### iPhone / iPad / Safari

1. 用 Safari 開啟 GitHub Pages 網址。
2. 第一次保持網路連線並完整載入。
3. 點 Safari 的「分享」。
4. 選擇「加入主畫面」。
5. 從主畫面的 Exam Paw Grader 圖示開啟。
6. 正式使用前建議先關閉網路測試一次。

> iOS / iPadOS 請優先使用 Safari 的「加入主畫面」方式。不同系統與瀏覽器版本的選單文字可能略有差異。

## 完整操作流程

### 1. 準備學生名單

學生名單至少需要兩欄：

```text
學號    姓名
S001    學生甲
S002    學生乙
S003    學生丙
```

可從 Excel 複製「學號、姓名」兩欄後直接貼到「名單 / Run」頁面。

按「匯入名單」後，設定每個 Run 的人數，再按「隨機排序並分 Run」。

### 2. 固定 Run 名單

確認隨機結果後按「固定目前 Run」。

固定後建議同時保留：

- **固定名單 Excel**：給學生、助教與其他教師查看，格式為 `Run｜組內順序｜學號｜姓名`。
- **固定名單 JSON**：供 Exam Paw Grader 日後重新匯入同一份固定 Run 名單。

如果換裝置或重新開始，也可以直接匯入固定名單 JSON，不必再次隨機排序。

### 3. 設定評分方式

進入「評分設定」。

每一個大題可以設定：

- 大題名稱
- 大題 icon
- 多個評分細項
- 每個細項的滿分

也可以自訂特殊事件，例如「做錯」、「提示」、「超時」等。

設定完成後，可輸入範本名稱並按「儲存目前設定」。同一台裝置可以保存多套課程評分範本，之後直接從選單套用。

若需要帶到另一台裝置，可使用「匯出評分設定 JSON」；另一台裝置再使用「匯入評分設定 JSON」。

### 4. 現場評分

進入「現場評分」，選擇目前 Run。

系統會列出該 Run 的學生以及目前狀態：未評、部分完成、完成或缺考。

學生到站後先詢問姓名，再點選正確學生進入評分。

- 細項滿分 **5 分以下（含 5）**：可直接按分數按鈕，也可輸入數字。
- 細項滿分 **大於 5 分**：使用 `−5`、`+5` 快速調整，也可直接點數字欄位輸入分數；手機／平板會使用數字輸入方式。
- 每個大題會自動計算總分。
- 所有大題完成後，可在成績頁查看最後平均。
- 特殊事件可直接點選留下紀錄。

每次分數異動都會立即寫入本機資料庫，不需要另外按「儲存」。

### 5. 下一位學生

完成目前學生後按「下一位學生」。

系統會重新顯示目前 Run 的所有學生與評分狀態，教師再依實際到站學生姓名選取，不強迫固定順序。

### 6. 缺考與考試中調整 Run

若考試進行中才確認有人缺考，可在名單中將該學生標記為「缺考」。

如果最後幾個 Run 因缺考而人數不足，可使用「移 Run」將尚未考試的學生移到其他 Run。系統會留下 Run 異動紀錄，不需要重新隨機整份名單。

### 7. 回頭修改以前的成績

進入「全部成績」，可以依 Run、學號或姓名找到任何學生，再按「查看 / 修改」。

從成績簿回頭修改時會進入歷史成績編輯模式。分數修改不只保存最新結果，也會留下修改紀錄，例如：

```text
原本 4 分 → 修改為 5 分
```

因此中場休息時可以回頭微調前面 Run 的評分，同時保留 Before / After 紀錄。

### 8. 考試途中備份

進入「救援 / 輸出」，按「下載完整救援 JSON」。

建議至少在以下時機各備份一次：

- 開考前完成名單與設定後
- 中場休息
- 大量評分完成後
- 考試結束時

如果瀏覽器資料發生問題或需要換裝置，可使用「載入救援 JSON」恢復考試資料。

### 9. 匯出最終成績 Excel

考試完成後按「匯出最終成績 Excel」。

主成績工作表是一位學生一列，並依當次自訂評分設定自動展開：

```text
Run｜組內順序｜學號｜姓名｜
大題一-細項A｜大題一-細項B｜大題一-總分｜
大題二-細項A｜大題二-細項B｜大題二-總分｜
最後平均
```

另外包含「事件紀錄」與「修改歷程」工作表，方便日後查核。

### 10. 開始下一輪考試

確認已經下載最終 Excel 與救援 JSON 後，使用「清除所有資料／新一輪考試」。

此功能會清除本次考試的：

- 學生名單
- Run
- 成績
- 特殊事件
- 修改紀錄

已儲存的課程評分範本會保留，可以直接用於下一次考試。

## 資料安全注意事項

評分資料主要保存在目前裝置與瀏覽器的 IndexedDB。請不要在考試進行中清除該網站的瀏覽資料、網站資料或瀏覽器儲存空間。

正式考試建議採用「本機自動儲存 + 定期下載救援 JSON + 考後 Excel」三層方式保留資料。重要階段下載的 JSON 建議另外複製到其他安全位置。

## 版本更新

程式頂端會顯示目前版本號。PWA 偵測到新版程式後會顯示更新通知，可按「立即更新並重新載入」。

考試正在進行時，如果目前版本運作正常，**不建議為了更新而中途重新載入**；可等考試結束並完成備份後再更新。

## 隱私

此公開專案不包含真實學生名單、學號、姓名或成績。README 中的學生資料皆為示意資料。

工具以離線評分為主要設計方向，主要資料可留在教師使用的裝置中。匯出的 Excel 與 JSON 可能包含學生資料與成績，請依所在單位的個資與成績管理規範保存。
